# CareerLens

AI-powered job application intelligence platform.

CareerLens helps candidates understand how their resume aligns with a job description, identify skill gaps, and create personalized preparation plans.

## Current Status

🚧 Under Development

- Axios

### Backend

- MongoDB
- Mongoose
