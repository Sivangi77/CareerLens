# CareerLens

CareerLens is a full-stack AI-powered Job Application Intelligence Platform that helps job seekers understand job requirements, measure their fit, identify skill gaps, and prepare strategically for interviews.

## Features

- 🔐 **Authentication & User Profiles**
  - Secure signup/login
  - User-specific application data

- 📋 **Application Tracker**
  - Create, update, and delete job applications
  - Track application status and deadlines
  - Application status history

- 📄 **Resume Intelligence**
  - Resume analysis and structured skill extraction
  - Identify relevant candidate skills

- 💼 **Job Description Intelligence**
  - Analyze job descriptions
  - Extract required and preferred skills
  - Understand role requirements

- 🎯 **Match Analysis**
  - Calculate candidate-job match score
  - Identify matched, partial, and missing skills
  - Provide skill-level fit breakdown

- 📚 **Skill Gap Analysis**
  - Identify missing and partially matched skills
  - Prioritize skill gaps
  - Generate actionable recommendations

- 🗺️ **Study Plan**
  - Convert skill gaps into a structured preparation plan
  - Track preparation tasks

- 🎤 **Interview Preparation**
  - Generate role-specific interview questions
  - Technical and behavioral preparation

- 📊 **Dashboard & Analytics**
  - Application KPIs
  - Application status distribution
  - Match-score distribution
  - Recurring skill-gap analysis
  - Interview conversion tracking
  - Upcoming deadlines and recent activity

- 🎬 **Public Recruiter Demo**
  - No-login interactive demo
  - Precomputed candidate and application data
  - Demonstrates the complete CareerLens workflow
  - Includes multiple realistic application scenarios

- 📖 **How It Works**
  - Explains the complete workflow from job description to interview preparation

## Core Workflow

Resume → Job Description → Match Analysis → Skill Gaps → Study Plan → Interview Preparation
